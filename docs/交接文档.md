### 关键发现（协议层）
1. 实时通道：`wss://api-cn.hellotalk8.com/ht_im/sock?userid=<uid>`
   - 客户端首帧（明文 JSON）：`{"jwt":"eyJhbGciOiJIUzI1NiIs...","mobile_op...}` → JWT claims `{exp,iat,src,uid}`
   - 服务端回帧（明文 JSON）：`{"status":0,"msg":"success","data":{"session_id":"...","session_key":"<SESSION_KEY>","need_update":0,"server_ts":...,"translate_api_ts":120,...}}`
   - **握手之后的 WS 负载全部是加密二进制**（应用层加密，session_key 参与）→ 要读 IM/打招呼协议必须先还原客户端加密算法
2. HTTP REST 流量稀少：App 主要走 WS + CDN（`ali-global-cdn.hellotalk8.com`、`h5.hellotalk8.com`）
3. 客户端本地状态：`say_hi_state_data<uid>`（SharedPreferences，记录已打招呼对象）、`vev.have_say_hi` 等
4. 打招呼「今日次数已用完」文案来自错误码映射表（`rdy.smali`，key=`Message exceeded the upper limit`，属服务端错误键）→ 倾向**服务端计数**，待实证
